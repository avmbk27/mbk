# Akıllı Asistan — Android başlangıç prototipi

Bu proje Kotlin + Jetpack Compose ile hazırlanmış başlangıç iskeletidir.

## Gerekenler
- Android Studio (güncel kararlı sürüm)
- JDK 17
- Android SDK 35

## Açma
1. ZIP dosyasını çıkarın.
2. Android Studio > Open ile `AkilliAsistanAndroid` klasörünü seçin.
3. Gradle senkronizasyonunu tamamlayın.
4. Bir Android cihaz veya emülatör seçip Run'a basın.

## Mevcut olanlar
- Ana ekran ve modül kartları
- Android bildirim erişimi ayarını açan düğme
- Bildirim dinleyici servisinin başlangıç iskeleti

## Henüz yapılmayanlar
- WhatsApp/arama bildirimlerini hatırlatma kuralları
- Hava durumu servisi ve uyarıları
- Yapay zekâ görsel üretimi/düzenleme bağlantısı
- Kalıcı veri saklama, ayarlar ve eklenti arayüzü

Not: Bu kaynak kod başlangıç iskeletidir; bu ortamda Android derlemesi yapılmış bir APK değildir.
